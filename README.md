# Buskila Lab website

GitHub Pages-ready static site for **buskilalab.com**.

## Publish on GitHub Pages
1. Create a repository named `buskilalab`.
2. Upload every file and folder from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then save.
6. In **Custom domain**, enter `buskilalab.com`.
7. Configure the GitHub Pages DNS records in Spaceship, then enable **Enforce HTTPS** after GitHub validates the domain.

## Before launch
- Replace placeholders on Team and Publications pages.
- Add approved photos to `assets/images` and update image references.
- Check every email address, phone number, affiliation and research description.
- Do not cancel Wix until the new domain resolves and all pages have been tested.

## Editing
All pages are plain HTML. Shared styling is in `assets/style.css`.
